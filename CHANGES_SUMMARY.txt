================================================================================
KEY DESIGN DECISIONS
================================================================================

Why DDR2 as Main RAM?
  - Artix-7 100T BRAM: only 4.86 MB total
  - TinyML models: 100 KiB - several MB each
  - DDR2 solution: 128 MB external RAM
  - L2 cache: 128 KiB makes DDR acceptable (~5 cycle latency)
  - Result: More BRAM available for caches and peripherals

Why 128 KiB ROM (not 256 KiB)?
  - BIOS actual usage: 27.86 KiB
  - 128 KiB provides 4× headroom for boot code
  - Saves BRAM for more critical resources
  - Sufficient for production bootloader

Why 128 KiB L2 Cache?
  - Typical TinyML hit rate: 80-90%
  - Larger caches have diminishing returns
  - 256 KiB option available if needed
  - Resource-efficient solution

Why 16 KiB I$/D$ Caches?
  - VexRiscv standard variant default
  - Good balance for embedded ML inference
  - 8 KiB option available for tight constraints
