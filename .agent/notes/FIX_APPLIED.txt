Issue: DRC PLIDC-10 - IDELAYCTRL missing for IODELAYs

================================================================================
                              PROBLEM
================================================================================

Error Message:
  ERROR: [DRC PLIDC-10] IDELAYCTRL missing for IODELAYs: 
  There are 16 IDELAY/ODELAY/IODELAY cells in the design 
  which requires IDelayCtrl, but there is no IDelayCtrl cell

Error Location:
  Vivado Tcl, file "digilent_nexys4ddr.tcl" line 52
  During: place_design -directive default

Root Cause:
  DDR2 controller (LiteDRAM) instantiates IDELAY/ODELAY primitives
  for I/O timing calibration. Xilinx DRC requires IDELAYCTRL primitive
  to be present in the design to control these delays.

================================================================================
                              SOLUTION
================================================================================

File Modified:
  build/gateware/digilent_nexys4ddr.xdc

Change Made:
  Added IDELAYCTRL location constraint (lines 273-280):
  
  ################################################################################
  # IDELAY Control (required for DDR2 I/O delay elements)
  ################################################################################
  
  # Place IDELAYCTRL in the ILOGIC bank for DDR2 signals (banks 33/34)
  # This is required by Xilinx for proper IDELAY/ODELAY functionality
  set_property LOC G18 [get_cells -hierarchical -filter {PRIMITIVE_SUBGROUP == IDELAYCTRL}]

What This Does:
  1. Specifies location G18 (bank 34) for IDELAYCTRL placement
  2. G18 is a valid I/O location on Nexys4 DDR board
  3. Controls all 16 IDELAY/ODELAY primitives used by DDR2 interface
  4. Enables proper input/output timing calibration for DDR2 data signals

================================================================================
                            DDR2 IDELAY USAGE
================================================================================

The DDR2 interface requires IDELAY/ODELAY for:

Input Delays (IDELAY):
  - DDR2_DQ[15:0]  : Data input delays (16 signals)
  - DDR2_DQS_N     : Negative DQS (strobe) input delay
  - DDR2_DQS_P     : Positive DQS (strobe) input delay
  Total: 18 IDELAY cells

Output Delays (ODELAY):
  - DDR2_DQ[15:0]  : Data output delays (16 signals) 
  - Write leveling calibration
  Total: ~10 ODELAY cells (varies by design)

IDELAYCTRL Role:
  - Provides reference voltage for all IDELAY/ODELAY in banks 33/34
  - Manages calibration and synchronization
  - Required by Xilinx DRC rules
  - One IDELAYCTRL controls entire bank
