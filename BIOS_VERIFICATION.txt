================================================================================
                      HOW BIOS IS EMBEDDED
================================================================================

Process:
  1. BIOS source code compiled to bios.elf
  2. ELF converted to bios.bin (raw binary)
  3. Build script generates Verilog ROM initialization
  4. ROM instantiated with BIOS data in digilent_nexys4ddr.v
  5. Entire SoC synthesized with embedded BIOS

Result:
  - BIOS is part of FPGA bitstream
  - No separate ROM file needed
  - No external bootloader required
  - Complete system boots from BIOS

Build Command:
  ./scripts/build.sh
  └─ Runs: python hw/build_soc.py
     └─ Compiles BIOS
     └─ Generates Verilog with BIOS ROM
     └─ Creates digilent_nexys4ddr.v (complete SoC)

================================================================================
                    TROUBLESHOOTING
================================================================================

If UART Shows No Output:
  1. Check UART settings: 115200 baud, 8-N-1
  2. Verify USB cable connection
  3. Try pressing ENTER to see prompt
  4. Check BIOS compilation in build log

If DDR2 Initialization Fails:
  1. BIOS will report error on UART
  2. Check DDR2 clock settings (should be 400 MHz)
  3. Verify write leveling calibration
  4. Try: litex> memtest (in BIOS console)

If Memory Test Fails:
  1. DDR2 may have timing issues
  2. Try lower system clock: --sys-clk-freq 80000000
  3. Check DDR2 module seating on board
  4. Verify CSR settings match board
